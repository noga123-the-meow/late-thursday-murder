# החידה שלנו · AliceCode

התחילו בפתיחת **START-HERE.html** אחרי חילוץ כל ה-ZIP. הוא כולל הוראות מדויקות לפעם הראשונה ופתרון תקלות.

עובדות על שלושה קבצים בלבד:

- `index.html`: כותרת, סיפור, חידה, שדה, כפתור ורמז.
- `style.css`: צבעים, תמונה ועיצוב.
- `script.js`: בדיקת הקוד ופתיחת הרמז, עם הערות בעברית.

`room.png` היא תמונה מקומית מוכנה. אפשר להחליף אותה בתמונה שלכן באותו שם או לשנות את הנתיב ב-CSS.

הפעלה: פותחים את index.html בדפדפן. JavaScript מופעל דרכו אוטומטית; אין צורך בהתקנת JavaScript, בתוסף, ב-Node.js או באינטרנט. לא לוחצים Run על script.js.

תשובת הדוגמה היא `42`. שנו את secretCode ואת החידה כך שיתאימו זו לזו. כאן הסוד גלוי בדפדפן; השרת המוגן מודגם בנפרד אצל המדריכה.

אין בספרייה הראשית חבילות או ספריות חיצוניות. אנימציית הפתיחה משתמשת ב-CSS. הרחבה אפשרית עם Anime.js מתוארת ב-EXTENSIONS.md, ואינה תנאי להפעלה.

תיקיית `node-practice` היא תרגול נפרד ואופציונלי לטרמינל: אין צורך לגעת בה כדי לבנות את המשחק.

התוצר המבוקש: דף חידה אחד מקורי. התחילו בסיפור, חידה ותשובה. לאחר בדיקת קוד נכון ושגוי, הוסיפו שינוי עיצובי או יכולת אחת משלכן.
